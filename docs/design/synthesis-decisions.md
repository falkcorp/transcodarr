# Synthesis Decisions and Naming Contract

Machine-generated by the design workflow. This is the binding record the section authors wrote against.

## Base design

**transcoderr Distributed Transcode Orchestrator — Day-2 Operations Design**

Base: Day-2 Operations. It is the only candidate whose primary axis is "what does the operator do when it breaks" — /diagnose, dispatch_block rows, per-attempt argv persisted before exec, capability history with diff summaries, config revisions with rollback, trash-on-by-default, drain/rolling-upgrade. Those are the parts a solo operator actually lives in, and they are the hardest to retrofit. Its data model (STRICT tables, idx_job_open_per_file, compare-and-swap transitions, immutable terminal rows) is the cleanest of the four, and its policy engine (typed TOML rules, emergent two-stage via the file's own audio codec, same_decision_streak convergence guard, dry-run diff) is correct without a DSL.

Grafts:
- From "durability-first": the commit_intent ledger with a partial unique index on live intents, the agent-local fsynced INTENT journal with phase markers, fencing epoch, and the explicit crash matrix. This is the fix for the base's single worst hole (no journal across the replace window). Also its NeedsOperator terminal state — ambiguity is never auto-resolved.
- From "throughput-first": the zero-await dispatcher critical section, sole-ownership ledger with no atomics, the DI-1 maximal-matching invariant plus the exhaustive "which event can flip which conjunct" table as a CI-checked artifact, and lossy-progress/lossless-results (watch vs mpsc) backpressure.
- From "transcoderr-orchestrator": requirement bucketing with precomputed agent eligibility bitsets (with numeric/path predicates deliberately excluded from the bucket key), the paired starvation metrics (slots_starved x unmatched{reason}), and M1-as-single-node-risk-retirement milestone ordering.
- Universal across all four: per-(codec,profile,bit_depth,accel) trial-decode capability with a distinct SoftFallback verdict that does not satisfy a hardware requirement.

Environment-specific overrides that supersede all four candidates: ZFS snapshots make in-place replacement reclaim nothing, so reclaim accounting reads zfs used/usedbysnapshots and a snapshot-policy preflight is mandatory; free space is reserved against one pool identity, never per-mount or per-agent; the DB location is validated by measured fsync latency, not fstype; the GPU node's rename semantics are proved by a rename-over-existing-open-file probe before it is commit-eligible; and cross-device work area is a hard dispatch gate, not a warning.

The system is built strictly bottom-up: pure core (no I/O) first, then store, then single-node executor with the full commit ritual, then protocol, then dispatch, then observability and UI.

## Fatal-flaw resolutions

- FIXED: A1 stale plan destroys HDR -> plan carries expected content_sig; agent aborts on mismatch; re-plan on every retry.
- FIXED: A2 lost JobResult re-encodes replaced file -> commit_intent ledger + agent journal; retry re-probes and re-plans, never reuses plan_json.
- FIXED: A3 Opus+require_smaller orphans video -> size policy is per-stage; audio uses may_grow; skip markers are per-decision-class, not per-file.
- FIXED: A4 two-rename window / non-POSIX rename -> single rename onto final after chown/chmod; rename-over-open probe gates commit eligibility per agent.
- FIXED: A5 fingerprint cardinality explosion -> bucket key excludes paths and byte thresholds; those become per-job admission checks with bounded scan.
- FIXED: A6 volatile capability inputs cached -> space and mount freshness moved out of the cached mask into per-job admission.
- FIXED: A7 send_offer blocks dispatcher -> try_send only; full channel marks agent unhealthy and returns job to queue; last_pass timestamp gauge.
- FIXED: A8 grants leak on Retrying -> release on leaving the admitted state set, not on terminal; ledger rebuilt from DB on boot.
- FIXED: A9 head-of-line behind global.large -> queues partitioned by size_bucket; bounded skip-with-pushback on inadmissible heads.
- FIXED: A10 cross-node GC deletes live work dirs -> work dirs namespaced by agent_uid+boot_id; GC touches only own namespace.
- FIXED: A11 cross-node recovery races rename -> recovery is intent-ledger driven and scoped to the owning agent, never a shared-root sweep.
- FIXED: A12 hwaccel has nowhere to live -> plan carries a decode-strategy matrix; agent selects accel from its own verdicts at exec.
- FIXED: A13/C2 single GPU agent + denylist dead-letters -> reject codes split capability-drift vs transient; transient never excludes, never dead-letters.
- FIXED: A14/C-writer coalesced txn rollback -> per-op SAVEPOINT isolation, poison quarantine, priority lanes, synchronous=FULL for commit records.
- FIXED: B1 loose duration tolerance -> asymmetric min(0.5%,5s) against last-packet PTS plus full decode-null pass with -xerror.
- FIXED: B2 duplicate of A2 -> same fix: intent ledger plus mandatory re-plan on retry.
- FIXED: B3 no destination re-stat -> re-stat dev/ino/size/mtime_ns immediately before rename; abort as SourceChanged.
- FIXED: B4 rename self-test inadequate -> probe renames over an existing open destination and verifies inode identity; failure blocks commit work.
- FIXED: B5 Atmos/DV-P7 loss -> DV profile 7 and object-audio titles excluded from all work by default; unknown DV vetoes.
- FIXED: B6 per-file min_shrink abandons stages -> shrink thresholds are per-stage and audio compares audio-stream bytes only.
- FIXED: B7 hardlink double-jobs -> file identity is (dev,inode); nlink recorded; hardlinked sources skipped by default.
- FIXED: B8 lossy durability for write-through -> probe write-through commits synchronous=FULL in its own transaction before ack.
- FIXED: B9 spec-match recovery unsound -> recovery keys on intent ledger state and an xattr job marker, never on spec resemblance.
- FIXED: B10 global large cap is FM5 -> per-class reservations inside the large pool; follow-up video jobs get priority boost.
- FIXED: B11 no event restores unhealthy agent -> AgentHealthRestored event plus a 5s unconditional safety pass.
- FIXED: B12 no encoder relaxation -> unmatched-for-N-minutes triggers re-plan against the next encoder in preference order.
- FIXED: B13 validation against stale facts -> minimum mtime age before enqueue plus start-time and commit-time source re-stat.
- FIXED: B14 temp path omits attempt -> temp path is job_id+attempt+agent_uid; agent refuses a job_id it already runs.
- FIXED: B15 SMB rename/ownership/hardlinks -> per-agent rename probe, explicit uid/gid/mode copy before rename, nlink>1 skipped.
- FIXED: B16 per-client space budgets -> reservations keyed on a server-assigned pool identity, never st_dev or mount path.
- FIXED: B17 no circuit breaker -> N consecutive failures with zero successes quarantines the agent; min_agent_version enforced at Register.
- FIXED: B18 scanner enters .zfs -> default exclusion list (.zfs, work, trash, @eaDir, lost+found) plus mass-missing scan abort guard.
- FIXED: C1 new buckets invisible -> bucket creation recomputes agent eligibility and emits a dispatch event.
- FIXED: C3 space head-of-line -> bounded backfill scan past inadmissible heads; always-admit-one forward-progress escape.
- FIXED: C4 no ledger rebuild on restart -> ledger reconstructed from Assigned/Running/Committing rows before first dispatch pass.
- FIXED: C5 duplicate of A8 -> release on leaving admitted state set.
- FIXED: C6/D9 graveyard reclaim is a lie on ZFS -> snapshot preflight; reclaim measured from zfs accounting; trash sized and reaped against pool pressure.
- FIXED: C7 triple-counted free space -> duplicate of B16; single pool-scoped budget.
- FIXED: C8/D10 NVENC session exhaustion poisons agent -> distinct EncoderSessionExhausted class, transient, sheds a GPU slot; overrides expire and are clearable.
- FIXED: C9 epoch bumps on reconnect -> epoch bumps only on new process instance; stream reconnect resumes the existing epoch.
- FIXED: C10 server not really validation authority + skew -> agent verdict is authoritative and signed by version; explicit min_agent_version and proto compat gate.
- FIXED: D1 no journal across replace -> phase-marked fsynced INTENT journal (GRANTED/RETIRED/INSTALLED) replayed on agent start.
- FIXED: D2 duplicate of A2/B2 -> re-plan on retry, intent-ledger idempotency.
- FIXED: D3 percentage duration tolerance -> duplicate of B1; absolute cap plus decode verification.
- FIXED: D4 cross-device work area warned -> hard dispatch gate per (agent, library, dataset); refuses to run otherwise.
- FIXED: D5 restart duplicates encodes -> lease expiry held for a reconnect grace; explicit Revoke message; commit requires a valid fencing token.
- FIXED: D6 dispatch_round livelock -> all four permits peeked before selection; commit_assignment has an explicit failure branch advancing the cursor.
- FIXED: D7 follow-up video starves behind audio -> per-class reservation within the large pool plus follow-up priority band.
- FIXED: D8 no Eligible->Blocked edge -> added, with unschedulable-work gauge and alert.
- FIXED: D11 fstype DB guard useless on all-ZFS -> startup fsync-latency probe with hard abort plus db_fsync_latency metric.
- FIXED: D12 workarea_same_device single boolean -> per-(agent,library) device resolution against the actual final path dataset.
- FIXED: D13 no ownership preservation -> fchown/fchmod/xattr copy from source stat before rename; failure fails the job.
- ACCEPTED: D14 work area on destination doubles pool I/O -> keep colocation for atomicity; local-NVMe staging is an explicit opt-in mode with copy-back.

## Subsystems

- **S0** Workspace split and legacy CLI fixes — Convert repo to a Cargo workspace with crates core/proto/store/server/agent/cli/testkit. Fix the two known bugs (dry-run creating dirs, silent unknown preset), replace the codec sentinel with Option<String>, drop the json feature, add 3-line headers to all new files. (depends on: none)
- **S1** Core media model and ffprobe parsing — Pure, I/O-free types: MediaInfo, Stream, StreamKind, BitDepth, ColorInfo, FileFacts, plus parse_ffprobe_json and derive_facts. Includes HDR/Dolby-Vision detection with an explicit Unknown tri-state that vetoes video work. (depends on: S0)
- **S2** Core path model and translation — CanonicalPath, AgentPath, MountTable, longest-prefix translate, plan_output_path, strict_stem, lexically-normalising paths_equivalent. All existing path helpers move here with the current_dir dependency replaced by an explicit base parameter. (depends on: S0)
- **S3** Core capability and requirements model — Capabilities, DecoderTriple, DecoderStatus (Ok/SoftFallback/Fail/Untested), Requirement enum, satisfies() returning UnmetRequirement. SoftFallback never satisfies a hardware requirement. Mount coverage is a requirement variant. (depends on: S1, S2)
- **S4** Core policy engine — Typed TOML rules, Match/Action, evaluate and evaluate_explained with RuleTrace, rules_version as blake3 of canonical TOML. Pure and deterministic. Produces Decision with independent audio and video stages plus block reasons. (depends on: S1)
- **S5** Core plan and argv builder — EncodePlan, StreamMap, ExpectedOutput, pix_fmt_for as an exhaustive match, decode-strategy matrix, build_ffmpeg_argv emitting explicit per-stream maps, chapters, metadata and attachments. Returns argv without argv[0]. (depends on: S3, S4)
- **S6** Core validation and failure classification — Ordered gate chain (exit, parseable, min bytes, decode-null with -xerror, asymmetric duration, per-type and per-track identity, bit depth, HDR preserved, then size last). FailureClass with retryability. All pure over probe data. (depends on: S5)
- **S7** Store schema and migrations — SQLite STRICT schema: library, file, file_stream, job, job_event, job_attempt, commit_intent, trash_entry, agent tables, dispatch_block, config_revision, schedule, scan_run. All indexes including the partial live-job and live-intent uniques. (depends on: S0)
- **S8** Store writer actor and read pool — Single writer thread with grouped commit, per-op SAVEPOINT isolation, poison quarantine, priority lanes (control before bulk). Read pool for API. Startup fsync-latency probe with hard abort. Compare-and-swap transition API. (depends on: S7)
- **S9** Job state machine and repository — JobState enum with const can_transition, JobRepo::transition writing job_event, admitted-state-set definition for permit release, Eligible->Blocked edge, dedupe keys as partial uniques only over live rows. (depends on: S8)
- **S10** Scanner and file upsert — Bounded blocking walk with exclusion list, identity by (dev,inode) with nlink recorded, idempotent upsert keyed on identity, mass-missing abort guard, scan_run accounting. Never deletes rows or discards probe data. (depends on: S8, S2)
- **S11** Prober and evaluator — Probe only new or changed files; evaluator re-derives decisions from stored facts in batches with library round-robin. Policy apply marks files dirty via one indexed update. Dry-run diff endpoint logic. (depends on: S10, S4)
- **S12** Agent executor and progress — Spawn ffmpeg without a shell, agent-local progress file, parse -progress, in-memory snapshots, timeouts based on progress stall not wall clock, inflight journal fsynced before exec, adopt-or-kill on restart. (depends on: S5)
- **S13** Commit ritual and intent journal — Preflight (space, same-device per library, nlink, rename-over-open probe), validate via S6, request grant, fsync phase-marked journal, ownership copy, single rename, trash entry, report. Idempotent replay of every crash point. (depends on: S6, S12, S9)
- **S14** Capability prober — Parse encoders/decoders/hwaccels, then trial-decode per triple asserting exit zero, expected frames, and stderr free of hwaccel-init failure. Reads cgroup cpu.max for effective cores. Re-probes on binary or driver change. (depends on: S3, S12)
- **S15** Protocol definition and codegen — proto files plus generated crate: Register with version gate, bidi Connect stream, unary RequestCommit/ReportCommit, Revoke, heartbeat with running set and mount re-stat, drain. Conversions to and from core types. (depends on: S3, S5)
- **S16** Agent session client — TLS or mTLS transport, register with min-version negotiation, epoch on process instance only, heartbeat, priority control channel with acks, re-validate requirements on receipt, drain and cleanup handling. (depends on: S15, S14, S13)
- **S17** Server session and agent registry — Serve the stream, authenticate before registration, maintain agent table plus capability history with diff summaries, lease bookkeeping in server monotonic time, reconnect grace, revoke, orphan reconciliation, per-agent circuit breaker. (depends on: S15, S9)
- **S18** Capacity ledger and admission — Exclusively owned counters: per-agent-per-class slots, global per-class, global large bucket with per-class reservations, pool-scoped byte budget. All-or-nothing acquire, release on leaving the admitted set, rebuild from DB on boot. (depends on: S9, S17)
- **S19** Dispatcher — Single task, zero await inside the matching pass, bucketed ready index with agent eligibility bitsets, permit-aware selection with bounded skip and backfill, try_send only, back-of-queue requeue with exclusions, dispatch_block recording. (depends on: S18, S3)
- **S20** Reconciler and recovery — Startup and periodic: lease expiry with grace, intent-ledger driven roll-forward or roll-back, NeedsOperator escalation on ambiguity, orphan temp cleanup scoped by agent namespace, trash reaper, fsck invariant checker. (depends on: S19, S13)
- **S21** Scheduler, limits and hot reload — Schedule windows, temporary overrides with expiry, effective-limit computation, drain-not-cancel semantics, zero-limit guard, ArcSwap config with config_revision rows and rollback, push RuntimeConfig to agents. (depends on: S18)
- **S22** Metrics and alerts — Prometheus registry with the full series list, starvation gauges split by blocked-by-cap versus matcher-found-nothing, reclaim measured from zfs accounting, shipped Grafana dashboard and alert rules under deploy/. (depends on: S19, S20)
- **S23** JSON API — axum /api/v1: libraries, files with explain, jobs with attempts and argv, agents with decoder matrix, queue with block reasons, policy with dry-run diff, schedule, trash, intents, diagnose, healthz, readyz. Keyset pagination. (depends on: S21, S22)
- **S24** Embedded web UI — Hand-written HTML plus one ES module and CSS, rust-embed with debug-embed false, SSE live updates. Views: overview with diagnose panel, agents, queue, job detail, files, policy, schedule, dead letter, logs. (depends on: S23)
- **S25** Deployment and docs — systemd units, WSL2 launcher and lifecycle checks, doctor preflight (fsync latency, rename probe, snapshot policy, pool free), rolling upgrade, README/TODO/TESTING/CHANGELOG updates and the R70 regression fixture set. (depends on: S24, S16)

## Naming contract

### Crates

- `transcoderr-core - pure domain: probe model, policy, capability matching, plans, validation; no I/O`
- `transcoderr-proto - tonic-build generated gRPC types from proto/transcoderr/v1/agent.proto`
- `transcoderr-store - rusqlite schema, migrations, Writer task, repositories, read pool`
- `transcoderr-server - dispatcher, scheduler, scanner, evaluator, reconciler, API, UI, metrics`
- `transcoderr-agent - capability probing, ffmpeg execution, commit ritual, intent journal`
- `transcoderr-cli - single bin `transcoderr` with server|agent|local|admin subcommands`
