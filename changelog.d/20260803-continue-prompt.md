### Added

#### `docs/design/CONTINUE-PROMPT.md`

A paste-ready prompt for resuming work in a fresh session with no prior context.
Carries the standing authority to run phases end-to-end and merge tested work
without asking, the current phase status, the three carry-forward items, the
environment quirks that have already cost time (no GitHub creds or git-lfs on
the server, zsh word-splitting, g-prefixed GNU tools), and the
media-correctness rules that must survive into the implementation.
